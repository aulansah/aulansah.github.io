Resep Makanan Indonesia

Aplikasi untuk memasak 10 makanan khas Indonesia di rumah, lengkap dengan bahan, langkah, dan kalkulator porsi. Mulai sebagai tugas belajar Android tahun 2021, sekarang dibangun ulang dalam lima stack untuk membandingkan cara kerja tiap teknologi.

  • Kotlin + Compose
  • Kotlin + XML
  • Java
  • Flutter
  • React Native

Dari tugas belajar jadi proyek portofolio

  1. 2021

    Tugas belajar Android

    Satu daftar makanan, satu halaman detail, dan halaman tentang. Kotlin dan XML, data langsung ditulis di kode.

  2. 2026

    Bisa dibuka lagi

    JCenter, sumber dependency versi 2021, sudah tutup, jadi build gagal sejak awal. Gradle, Kotlin, dan semua library dinaikkan ke versi terkini.

  3. 2026

    Desain sendiri

    Tema bawaan Android Studio diganti dengan desain terakota dan emas yang terasa seperti aplikasi kuliner.

  4. 2026

    Yang tampak jadi benar-benar jalan

    Pencarian ternyata hanya teks diam, chip filter tidak bisa diklik, tombol favorit hanya memunculkan toast, dan beberapa foto hilang. Semuanya diperbaiki, lalu Room ditambahkan agar data tidak lagi hidup di kode.

  5. 2026

    Compose, Hilt, tes, CI

    Tampilan pindah dari XML ke Jetpack Compose dengan satu Activity. Ditambah Hilt, tes unit untuk ViewModel, R8 untuk build rilis, dan GitHub Actions.

  6. 2026

    Tujuan yang jelas: memasak

    Katalog saja tidak memberi alasan untuk dibuka lagi. Sekarang tiap makanan punya bahan, langkah memasak, dan kalkulator porsi untuk 1 sampai 20 porsi.

  7. 2026

    Lima versi

    Aplikasi yang sama dibuat ulang dengan Kotlin XML, Java, Flutter, dan React Native. Isi datanya identik, hanya cara membangunnya yang berbeda.

Satu bug yang mengajarkan banyak

Foto makanan tidak muncul, padahal berkasnya ada. Penyebabnya ada di cara foto disimpan.

Sebelum

ID gambar disimpan di database sebagai angka. ID itu dibuat Android saat build dan bisa berubah di build berikutnya, jadi angka lama menunjuk ke gambar yang salah atau tidak ada.

photo = 2131230843   // angka dari R.drawable
Sesudah

Database menyimpan kunci teks yang tidak pernah berubah. Satu kelas kecil menerjemahkannya ke gambar saat ditampilkan, dan ada tes yang memastikan setiap kunci menghasilkan gambar.

photo_key = "rendang"
PhotoResolver.resolve("rendang")

Lima cara membangun aplikasi yang sama

Fiturnya sama di semua versi. Yang dibandingkan adalah cara UI dibuat, state dikelola, dan data disimpan.
